# Getting support

- **Questions, ideas, show & tell:** [GitHub Discussions](https://github.com/publisle/publisle/discussions)
- **Documentation:** [publisle.xyz/docs](https://publisle.xyz/docs/) · try it in the [Playground](https://publisle.xyz/playground/)
- **Reproducible bugs:** open an issue in [publisle/publisle](https://github.com/publisle/publisle/issues/new/choose)
  (TypeScript packages, adapters, site, PDF service) or
  [publisle/publisle-rs](https://github.com/publisle/publisle-rs/issues/new/choose) (Rust engine/crates),
  using the reproduction template.
- **Security issues:** see [SECURITY.md](SECURITY.md) — never in public issues.

Publisle is maintained by volunteers; there is no paid support. Clear,
minimal reproductions get the fastest answers.
