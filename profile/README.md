Publisle treats an article as validated, portable data: write in Markdown, then
render it as static HTML through Astro, Svelte, React, Vue or Next adapters,
add interactive blocks only where you need them, and export research-grade PDF.

| Repository | What it is |
| --- | --- |
| [**publisle/publisle**](https://github.com/publisle/publisle) | TypeScript core: schema, contracts, Markdown, blocks, framework adapters, CLI, research/PDF export and the publisle.xyz site. Packages on npm under [`@publisle`](https://www.npmjs.com/org/publisle). |
| [**publisle/publisle-rs**](https://github.com/publisle/publisle-rs) | Rust: the native PDF engine (`publisle-pdf`), math typesetting (`publisle-math`), and the upcoming Rust core and CLI. Crates on [crates.io](https://crates.io/search?q=publisle). |
